# Manguezais SP revela divergências entre monitoramento de campo e satélite

**Programa:** territorio-energia · **Domínio:** Meio Ambiente / Território  
**Status:** OBSERVED · **Data:** 2026-09-12

---

## Pergunta

O monitoramento de manguezais por satélite é consistente com dados de campo?

## Descoberta

O case Manguezais SP (4.000 pontos, 7 anos, 364 artigos, 9 territórios) revelou divergências entre monitoramento de campo e dados de satélite que a literatura não explica. O cruzamento de séries temporais de satélite com dados de campo mostrou padrões que nenhuma fonte individual revela.

## Implicação

O monitoramento territorial não pode depender de uma única fonte. O cruzamento satélite + campo + literatura é necessário para inteligência territorial confiável.
