# SIGMINE Mineral Retrieval combina embeddings + clustering + score híbrido para prospecção

**Programa:** mineracao-materiais · **Domínio:** Mineração  
**Status:** INFERRED · **Data:** 2026-09-12

## Pergunta

É possível fazer prospecção mineral automatizada com dados abertos?

## Descoberta

O pipeline SIGMINE v1/v2 combina âncoras da ANM → embeddings AlphaEarth → clustering → retrieval estrutural → delta temporal → score híbrido → validação. Notebooks implementam o ciclo completo com dados abertos (SIGMINE, Sentinel-2).

## Implicação

A prospecção mineral pode ser feita com dados abertos e embeddings de satélite, reduzindo drasticamente o custo de exploração.

## Próximo passo

Publicar o pipeline como método de referência para prospecção mineral de baixo custo.
