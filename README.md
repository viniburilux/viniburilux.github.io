# Vinícius Buri Lux — site autoral

Esta é a superfície web autoral de [Vinícius Buri Lux](https://github.com/viniburilux), pesquisador independente e construtor de sistemas de investigação sediado em Salvador, Bahia.

A raiz apresenta a autoria. As páginas seguintes organizam o ecossistema em camadas:

| Caminho | Função |
|---|---|
| `/` | Vinícius Buri Lux, bio, links e primeira entrada |
| `/luxverso/` | Ecossistema LUXVERSO |
| `/research-build/` | Modo de operação |
| `/projects/` | Projetos e linhas de investigação |
| `/infrastructure/` | TraceFoundry e fronteira com LuxMemory |
| `/evidence/` | Publicações, aceites e artefatos |
| `/timeline/` | Trajetória |
| `/docs/` | Documentos e ensaios |

A página original do projeto GhostWorks foi preservada em `ghostworks-legacy.html` durante a reorganização da raiz. As páginas de projeto existentes — Barcelona, LuxSense, LuxHub, Gnuvem e GhostWorks Itaparica — permanecem no repositório.

## Estado epistemológico

A superfície distingue observação, inferência, hipótese, insuficiência, bloqueio, rejeição e contradição. Aceite condicional não é convertido em aceite definitivo; aceite não é convertido em publicação.

## Desenvolvimento local

Como o site é estático, qualquer servidor HTTP simples pode servir o diretório. Nenhum conteúdo privado, credencial, prompt, trace ou estado interno deve ser adicionado a este repositório.
